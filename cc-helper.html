The dispatch loop 派活闭环

A bot that has the plugin writes a task on your machine. The desktop Helper runs it. The bot reads the result, or stops the run. 装了插件的机器人把任务写到你的电脑上。桌面 Helper 执行。机器人读结果，或者把这次运行停掉。

  1. 1 Write写入

    One JSON file in %USERPROFILE%\cc-helper\inbox\. 一份 JSON，放进 %USERPROFILE%\cc-helper\inbox\。

  2. 2 Run执行

    The Helper runs Claude Code or the Cursor CLI on that machine. Helper 在这台电脑上运行 Claude Code 或 Cursor CLI。

  3. 3 Watch看进度

    running\ gets status.json and progress.md. Finished work moves to done\. running\ 里有 status.json 和 progress.md。结束后进入 done\。

  4. 4 Stop停止

    Write stop into control\<task-id>.cmd. 往 control\<task-id>.cmd 写入 stop。 

{
  "id": "example-001",
  "title": "smoke write hello",
  "prompt": "Create hello.txt with HELLO_OK in the workspace root and stop."
}

Use a new id for every task. Do not put API keys in the JSON. 每个任务用新的 id。不要把 API key 写进 JSON。

Free · MIT免费 · MIT

Thin Cursor plugin薄 Cursor 插件

Skills, a safety rule, and a soft shell hook. The cc-helper-dispatch skill tells the bot how to write the inbox file, poll status, and stop. check-cc-helper looks for a local install. The hook only warns on a few risky shell patterns — it does not block the editor. Skills、一条安全规则，和一个软的 shell hook。cc-helper-dispatch 教机器人怎么写 inbox、轮询状态、停止任务。check-cc-helper 检查本机是否已安装。hook 只对少数危险 shell 模式给出警告，不会拦住编辑器。

The plugin does not include the daemon, the tray, the realtime panel, Bark, webhooks, or budget caps. 插件不含常驻进程、托盘、实时面板、Bark、webhook，也不含预算上限。

Set up 安装

  1. 1 Add the plugin加上插件

    Clone cc-helper-plugin into ~/.cursor/plugins/local/cc-helper and reload Cursor. When it is listed, you can also install it from the Cursor Marketplace or Grok Bot Connect Apps. 把 cc-helper-plugin 克隆到 ~/.cursor/plugins/local/cc-helper，然后重新加载 Cursor。市场上架之后，也可以从 Cursor Marketplace 或 Grok Bot Connect Apps 安装。

  2. 2 Start the Helper启动 Helper

    Install the Windows desktop Helper and leave the tray running. The plugin cannot start that daemon for you. 安装 Windows 桌面 Helper，并让托盘保持运行。插件自己启动不了那个 daemon。

  3. 3 Dispatch派活

    Ask the bot to use cc-helper-dispatch. It checks for %USERPROFILE%\cc-helper\daemon.js before it writes a task. 让机器人使用 cc-helper-dispatch。它会先确认 %USERPROFILE%\cc-helper\daemon.js 在，再写任务。

FAQ 常见问题

Is the plugin enough by itself?只装插件够不够？

No. The plugin teaches the bot how to write a task, read status, and stop. Running the task and watching it in real time needs the desktop Helper on your Windows machine.

不够。插件只教机器人怎么写任务、读状态、停止。真正执行和实时监督，需要你 Windows 电脑上的桌面 Helper。

What does Free include?Free 包含什么？

The MIT plugin, and — once the Helper is installed — the dispatch loop: write, run, watch progress, stop. Free does not enforce a budget cap, does not kill a timed-out run, and does not send Bark or webhook alerts.

MIT 插件，以及装上 Helper 之后的派活闭环：写入、执行、看进度、停止。Free 不设预算硬顶，不会超时判死，也不发送 Bark 或 webhook。

What does Pro add?Pro 多什么？

Three controls on the desktop Helper. A hard budget cap stops the run when the ceiling is hit. A timeout marks an over-limit run dead and stops it. Bark or a webhook can alert you. You turn these on with an activation code.

桌面 Helper 上的三样控制。预算硬顶：碰到上限就停。超时判死：超过时限就判定已死并停掉。Bark 或 webhook 可以通知你。用激活码打开。

Which systems does it support?支持哪些系统？

The desktop Helper is a local Windows install (daemon and tray). Add the plugin in the Cursor that will dispatch, on the machine where that Windows profile lives.

桌面 Helper 是 Windows 本机安装（daemon 和托盘）。把插件加到负责派活的 Cursor 上，也就是这份 Windows 用户目录所在的电脑。

Where do tasks go?任务存在哪里？

Under %USERPROFILE%\cc-helper\ on your PC. This page does not receive task text, prompts, or keys. Do not paste secrets into task JSON or logs.

在你电脑的 %USERPROFILE%\cc-helper\ 下面。这个页面不接收任务正文、提示词或密钥。不要把秘密写进任务 JSON 或日志。
