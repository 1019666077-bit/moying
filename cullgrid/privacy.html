Privacy Policy — CullGrid

Last updated: October 9, 2026

CullGrid is a browser extension that helps you bulk-move items to Recently Deleted in your own iCloud Photos web tab (icloud.com / icloud.com.cn).

CullGrid is not affiliated with Apple Inc. iCloud and Apple are trademarks of Apple Inc.

Operator

CullGrid is operated by 东莞市常平创客汇网络技术工作室 (Dongguan Changping Chuangkehui Network Technology Studio), also doing business as Moying Studio.

Privacy / support contact: moying.studio@outlook.com

Summary

We do not collect your photos, filenames, faces, location, Apple account credentials, or browsing history. Automation runs locally in your browser on the iCloud Photos page you already signed in to. The extension does not upload photo bytes to CullGrid servers.

Data the extension handles

Data Where it lives Leaves your device?
Lifetime free-tier confirm count (up to 50 successful moves to Recently Deleted) chrome.storage.local on this browser No
Consent / safety notice flags, last-run summary, popup settings chrome.storage.local (or session UI only) No
Activation (license) token after you paste a code chrome.storage.local; verified with local WebCrypto (Ed25519) No — verification does not call a CullGrid license API
Photo contents, filenames, faces, EXIF, Apple account data Never read for upload, analytics, or sale No

Browsing, filtering, and preview do not spend free-tier confirms. Only a successful confirmed move into Recently Deleted counts.

Permissions

  • storage — store the free-tier count, consent flags, and activation token locally.
  • Host access for iCloud Photos (https://www.icloud.com/photos/*, …/applications/photos3/*, and the matching icloud.com.cn hosts) — run a content script on the Photos UI you opened so CullGrid can use the page’s own selection and Delete controls.

There is no analytics SDK, no advertising network, no third-party tracker, and no remote code execution inside the extension.

Checkout (optional Pro unlock)

If you choose Upgrade, CullGrid opens a Waffo checkout URL in a new browser tab. Payment card and billing details are entered on Waffo’s page, not inside the extension. CullGrid does not receive or store your card number.

After payment, you receive an activation code (MVP: issued manually by support after the order). You paste that code in the CullGrid popup. The code is checked locally with a public key; no photo data is involved.

Order email and payment records held by Waffo are governed by Waffo’s own privacy policy. We may use your order email and order id only to deliver the activation code and handle support or refunds.

How CullGrid talks to iCloud

CullGrid does not call a private Apple write API and does not export your cookies off-device. It drives the same Delete / confirm UI you would click yourself in the signed-in Photos tab. Your Apple Account session stays between you and Apple.

Items move to Recently Deleted (typically restorable for about 30 days). CullGrid does not empty Recently Deleted for you.

Children

CullGrid is not directed at children under 13.
