# Moying · 墨英

English names and short words, drawn as Chinese brush marks.

## Run locally

```bash
python3 -m http.server 8765
```

Open http://127.0.0.1:8765/

Fonts load from jsDelivr (Google Fonts). No local `.ttf` files are required.

## GitHub Pages

1. Open the repo on GitHub.
2. Settings → Pages.
3. Branch: `main`, folder: `/` (root).
4. Save. The site is https://1019666077-bit.github.io/moying/

## Features

- Styles: Neat, Regular, Flowing, Grass, Wild
- Horizontal / vertical
- Rice, aged, night paper
- Ink / cinnabar
- Size, space, dry brush, red seal
- Export PNG, JPG, WebP, transparent PNG, SVG
- PDF saves a JPG instead
- Free preview is watermarked. The $1.99 button only shows an alert; payment is not connected.
