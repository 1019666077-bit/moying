# Moying · 墨英

English names and short words rendered as Chinese brush calligraphy.

Static web prototype. Open `index.html` locally (keep `fonts/` and `vendor/` next to it), or enable GitHub Pages.

## Run locally

```bash
bash scripts/fetch-fonts.sh
python3 -m http.server 8765
```

Then open http://127.0.0.1:8765/

## Features

- English short words / names
- Styles: Neat, Regular, Flowing, Grass, Wild
- Horizontal / vertical
- Rice, aged, night paper
- Ink / cinnabar
- Size, tracking, dry brush, red seal
- Export PNG, JPG, WebP, transparent PNG, SVG, PDF
- Free preview is watermarked; $1.99 clean download is not wired yet
